# 用选址片的同一位女声讲自己的系统

在新项目里改一份文案，就能重新配音。模板里的「打开工单，派给机修一组」由这套工具实际生成，可以先听[模板旁白](../public/audio/旁白.wav)。

1. 把 Skill 的整个 `assets/remotion` 文件夹复制成自己的制作工程。用纯文本编辑器打开该工程里的 [旁白.txt](旁白.txt)，换成自己的中文文案，保留句号、逗号和自然停顿。
2. 在 **M 系列芯片的 Mac** 上双击同目录的 [生成女声.command](生成女声.command)。首次需要 uv；已装 Homebrew 时可以运行 `brew install uv`。工具用 Python 3.11 准备固定版本的依赖，首次联网下载约 2.3 GB 的模型。已准备同版本模型的电脑可将环境变量 `EVCS_REFERENCE_TTS` 指向本地模型目录。
3. 等终端出现「旁白已生成」，打开或刷新 Remotion Studio 的 **ProductFilm**。名为「团队女声」的音轨读取新工程的 `public/audio/旁白.wav`。每次成功生成都会更新这个文件。如果使用 Windows 或 Intel Mac，可请队友在 M 系列 Mac 上生成 WAV，将它放入自己工程的同一位置，继续剪辑和导出。

如果系统双击时没有启动，在工程根目录打开终端运行：

```sh
zsh 配音/生成女声.command
```

也可以直接在 Codex 里说：

> 请用 $product-screen-film 的内置女声给【项目目录】中的【文案文件】配音。一次讲完整稿，沿用选址片的音色和正常语速。把生成的 WAV 接到 Remotion Studio 的主旁白轨，并按实际语音调整字幕和镜头。

**换了长稿后**，先听首句、产品名、数字和最后一句。终端会显示新录音的实际时长和对应的最低画面帧数。模板练习只有 5.4 秒，应按新稿的长度补足镜头，逐句对齐字幕。更长的讲解可按自然段录制，在停顿处衔接，所有段落沿用同一份声音配置。

**声音怎么复现**。工程保留了选址片的 14.8 秒女声参考样音、参考原文、随机种子、采样参数和录音脚本。生成前会核对样音指纹，并使用固定版本的 Qwen3-TTS 1.7B Base 4-bit 与 MLX Audio。换系统只需改旁白文案。
